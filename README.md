## 🚀 Как пользоваться
1. Нажми на название нужного задания в списке выше.
2. Прочитай теорию и подводные камни.
3. Скопируй код-шаблон из файла `.py` (Python) или `.cpp` (C++).
4. Вставь в свой редактор, подставь данные из условия задачи и запусти.
