# Задание 27. Кластеризация

## Суть задания
Разбить точки на соответствующие им кластеры и найти координаты центроидов этих кластеров
p.s. "значения, которые нужно найти могут сильно отличаться в разных заданиях. Например где-то надо найти радиус описаной вокруг кластера окружности и так далее."

## Теория:
* Независимо от того, какой файл вам предоставили (текстовый или excel) вам нужно:
    * Создать текстовый файл со всеми точками и ОБЯЗАТЕЛЬНО заменить запятые на символ точки, иначе программа НЕ БУДЕТ РАБОТАТЬ.
    * Создать файл в табличном редакторе (LibreOfficeCalc или другие), внести и разделить данные по столбцам, по ним построить точечную диаграмму (данные не должны содержать точек, только запятые).
* При разбиении точек на кластеры, внимательно смотрите на свою диаграмму, так как при не точных границах, ответ получиться не верный.
* Если вы вдруг забыли как писать функцию dist, она есть в библиотеке math и работает по такому же приинципу.
* После разбиения вам, зачастую, нужно найти координаты центроида кластеров

## Поднодные камни!
* ЧИТАЙТЕ ЗАДАЧУ, в каждой задаче может попасться другое определение центроида (например, центроид - это точка с максимальной суммой расстояний до всех других точек кластера).
